## Publish

Put this whole `housewarming-Usha-Chethan` folder in the same GitHub repository and branch as your `rachana-weds-mohan` folder (the repository that serves shashankabcbuilds.in), then commit. No DNS changes are needed.

## Sharing on WhatsApp

Share this link:

`https://shashankabcbuilds.in/housewarming-Usha-Chethan/?v=2`

WhatsApp remembers a link's preview. If you change the preview later, share it with a new number, for example `?v=2`.

Personal greeting: add a name after `#`, for example
