## Publish

Put this whole `chetan-usha-housewarming` folder in the same GitHub repository and branch as your `rachana-weds-mohan` folder (the repository that serves shashankabcbuilds.in), then commit. No DNS changes are needed.

## Sharing on WhatsApp

Share this link:

`https://shashankabcbuilds.in/chetan-usha-housewarming/?v=1`

WhatsApp remembers a link's preview. If you change the preview later, share it with a new number, for example `?v=2`.

Personal greeting: add a name after `#`, for example
`https://shashankabcbuilds.in/chetan-usha-housewarming/?v=1#Ramesh-Uncle`
